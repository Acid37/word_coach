四种支持的词表格式

JSON 数组（推荐，字段最全）：

[
  {"word": "apple", "phonetic": "/ˈæpl/", "meaning": "n. 苹果", "example": "an apple a day"},
  {"word": "give up", "meaning": "放弃"}
]

JSON 字典（最简，只有词和释义）：

{"apple": "n. 苹果", "book": "n. 书 v. 预订"}

CSV / TSV（Excel 另存为 UTF-8 CSV 即可）：带表头时列名支持中英双语 （word/单词、meaning/释义、phonetic/音标、example/例句、tags/标签）；无表头时按此顺序排列。

纯文本：每行一个词，后面可跟释义（Tab 或空格分隔），# 开头为注释。

开源词库字段也能直接用

主流开源词库常用的字段名已自动兼容： name/entry → word、trans/definition/chinese → 释义、 usphone/ukphone/pron → 音标、sentence → 例句。

更多词库怎么找

内置的四六级词库来自 kajweb/dict（3500+ Star）， 该仓库还有雅思、托福、GRE、SAT 等词库，但都是 zip 打包的 JSON Lines 格式（每行一个 JSON 对象）， 需要下载解压后用「上传本地文件」导入。另一个大词典项目是 ECDICT（8000+ Star）， 提供完整英汉词典 CSV（65MB），适合需要大量词条的场景。

怎么拿到 GitHub 上词库的直链

在 GitHub 打开词库文件 → 点右上角「Raw」→ 复制浏览器地址栏的 raw.githubusercontent.com/… 链接，粘贴到上面「从 URL 下载导入」即可。

配置自己的预置词库（让「一键导入」更方便）

编辑 config/plugins/word_coach/config.toml 的 [source] 节：

[source]
preset_urls = { kaoyan = "https://example.com/kaoyan.json", ielts = "https://example.com/ielts.json" }

保存后重启 Bot，页面「预置词库」下拉框即可一键导入；聊天里也可以直接说 「下载词库 kaoyan」。另外 auto_import_urls 可在词书为空的启动时自动下载（按顺序尝试，成功即停）。
